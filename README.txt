In this lab, I implemented a small wireless network consisting of a switch, a router, two laptops, one mobile phone, one Access Point (AP), one Wireless LAN Controller (WLC), and one RADIUS server.

The router acts as the DHCP server and provides IP address assignment for the clients.

The AP broadcasts an SSID named "Teszt" and successfully joined the WLC using a CAPWAP connection.

The WLC centrally manages the AP and provides wireless network configuration.

The RADIUS server is used for centralized authentication of wireless clients.
